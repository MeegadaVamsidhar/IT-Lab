# Exam System (MCQ)

This is a minimal production-like demo of an online MCQ exam system using:
- Node.js + Express
- SQLite (better-sqlite3)
- JWT authentication + bcrypt password hashing

Run:

```bash
npm install
npm start
```

Notes:
- Admin account seeded: admin@exam.com / Admin@123
- Examiner: examiner@exam.com / Exam@123
- Student: student@exam.com / Stu@123
